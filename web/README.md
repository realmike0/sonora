# Sonora Web
Player indipendente (un solo file, `index.html`, JavaScript ES5 senza librerie): funziona su qualsiasi browser, anche sui telefoni con Android < 8.
Ascolta tramite il lettore incorporato di YouTube, cerca con le API pubbliche Piped e salva i preferiti sul dispositivo. Con un Sonora ID sincronizza i preferiti (le dediche restano solo nell'app).
Per usarlo basta aprire `index.html` o pubblicare la cartella `web/` (GitHub Pages: Settings → Pages → Source: GitHub Actions).
