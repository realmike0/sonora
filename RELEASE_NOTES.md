## Sonora 0.80-beta

**New**
- AI rating for artists and albums (pie chart + a vote for every song)
- AI queue remix
- AI daily picks
- Voice search
- Turkish, Albanian and French
- Song dedications, visible to everyone with a Sonora ID
- Audio haptics (with a sensitivity slider)
- Output device switcher (Bluetooth / Chromecast)
- Improved widgets
- Sonora Web, a separate player in the `web/` folder for older browsers and devices
- F-Droid repository and Obtainium support

**Sonora ID**
- Email is now stored encrypted and verified with a 6-digit code
- Verification is only needed for dedications, sync works as before
- Sessions last 90 days

**Removed**
- Song recognition (it didn't work)

**Install**
- F-Droid: https://realmike0.github.io/sonora/fdroid/
- Obtainium: add `https://github.com/realmike0/sonora` and turn on pre-releases
- Or download the APK below
